# 控制板与低频通感设备接口说明

## 1. 范围与命名

本文档整理控制板与低频通感设备之间的接口关系，用于后续接口规范、联调说明和状态机数据包设计。

当前按以下命名理解：

| 本文档名称 | 物理架构图/设计文档中的对应模块 |
|---|---|
| 控制板 | 转化模块 DSP / DSP 状态机 |
| 低频通感设备 | 毫米波通感系统，包含毫米波通感系统-射频模块、毫米波通感系统-基带模块 |
| 低频通感基带 | 毫米波通感系统-基带模块 |
| 低频通感射频 | 毫米波通感系统-射频模块 |

说明：现有文档已明确低频通感设备向 DSP 提供角度、距离、速度、目标有效标志等感知信息；物理架构图中还标注了控制是否启用、通信参数、通信/感知数据等链路。但控制板与低频通感基带之间的具体电气物理口类型未在现有文档中明确标死，因此本文档将其标为“待硬件确认”。

## 2. 接口总览

| 编号 | 接口名称 | 方向 | 物理口 | 数据形式 | 主要用途 |
|---|---|---|---|---|---|
| LF-IF-01 | 低频目标感知数据接口 | 低频通感基带 -> 控制板 | 待硬件确认，当前图中表现为数字通信链路 | 周期性结构化数据包 | 搜索目标、粗对准、回退恢复、跟踪辅助 |
| LF-IF-02 | 低频通感启停控制接口 | 控制板 -> 低频通感基带/射频 | 待硬件确认，当前图中表现为控制链路 | 控制命令/状态位 | 控制低频通感设备是否启用、扫描或辅助跟踪 |
| LF-IF-03 | 低频通信参数配置接口 | 控制板 -> 低频通感基带 | 待硬件确认，当前图中表现为数字通信链路 | 参数配置数据包 | 下发通信参数、工作模式、阈值和 slot 配置 |
| LF-IF-04 | 低频通信/感知数据接口 | 低频通感基带 <-> 控制板/上层链路 | 待硬件确认，当前图中表现为数字通信链路 | 通信数据帧/感知数据帧 | 支持通信与感知信息交互 |
| LF-IF-05 | 低频设备在线/健康状态接口 | 低频通感基带/射频 -> 控制板 | 待硬件确认，可复用数字通信链路 | 状态字/心跳包 | S0 自检、故障检测、联调状态显示 |

## 3. 详细接口定义

### 3.1 LF-IF-01 低频目标感知数据接口

| 项目 | 内容 |
|---|---|
| 方向 | 低频通感基带 -> 控制板 |
| 发送方 | 毫米波通感系统-基带模块 |
| 接收方 | 转化模块 DSP / 控制板 |
| 物理口 | 待硬件确认；现有设计图未标出具体接口类型 |
| 数据形式 | 每 slot 周期上报的结构化目标数据包 |
| 对应状态 | S1 搜索、S2 粗对准、S4 跟踪辅助、S5 回退恢复 |

建议字段：

| 字段 | 含义 | 建议类型 |
|---|---|---|
| `slot_id` | slot 序号 | `uint32` |
| `target_valid` | 目标有效标志 | `uint8/bool` |
| `target_id` | 目标编号，多目标场景使用 | `uint16` |
| `azimuth_deg` | 方位角 | `float32` 或定点数 |
| `elevation_deg` | 俯仰角 | `float32` 或定点数 |
| `range_m` | 距离 | `float32` 或定点数 |
| `radial_speed_mps` | 径向速度 | `float32` 或定点数 |
| `snr_db` | 信噪比/置信度 | `float32` 或定点数 |
| `track_quality` | 跟踪质量或稳定度 | `uint8` |
| `timestamp` | 时间戳，可与 1PPS/系统时钟对齐 | `uint64` |

状态机使用方式：

| 状态 | 使用方式 |
|---|---|
| S1 搜索 | 连续若干 slot `target_valid=1` 且角度/距离稳定后进入 S2 |
| S2 粗对准 | 控制板根据 `azimuth_deg/elevation_deg` 计算云台转向目标 |
| S4 跟踪 | 低频感知作为太赫兹跟踪的辅助信息 |
| S5 回退 | 太赫兹失锁后，依靠低频目标数据判断是否恢复到 S2 |

### 3.2 LF-IF-02 低频通感启停控制接口

| 项目 | 内容 |
|---|---|
| 方向 | 控制板 -> 低频通感基带/射频 |
| 发送方 | 转化模块 DSP / 控制板 |
| 接收方 | 毫米波通感系统-基带模块，必要时由基带转发到射频模块 |
| 物理口 | 待硬件确认；现有图中标注“控制是否启用” |
| 数据形式 | 控制命令包或控制位 |
| 对应状态 | S1、S2、S4、S5 |

建议字段：

| 字段 | 含义 | 建议类型 |
|---|---|---|
| `slot_id` | slot 序号 | `uint32` |
| `rf_enable` | 射频启用 | `uint8/bool` |
| `sense_enable` | 感知启用 | `uint8/bool` |
| `scan_mode` | 扫描模式，如搜索、定向、辅助跟踪 | `uint8` |
| `beam_id` | 波束编号，可选 | `uint16` |
| `gain_index` | 增益档位，可选 | `uint8` |
| `command_seq` | 命令序号 | `uint16` |

状态机使用方式：

| 状态 | 使用方式 |
|---|---|
| S1 搜索 | 启用低频扫描/搜索模式 |
| S2 粗对准 | 保持低频感知开启，提供持续角度更新 |
| S4 跟踪 | 作为辅助感知链路，可选择保持开启 |
| S5 回退 | 确保低频感知开启，用于恢复目标 |

### 3.3 LF-IF-03 低频通信参数配置接口

| 项目 | 内容 |
|---|---|
| 方向 | 控制板 -> 低频通感基带 |
| 发送方 | 转化模块 DSP / 控制板 |
| 接收方 | 毫米波通感系统-基带模块 |
| 物理口 | 待硬件确认；现有图中标注“通信参数” |
| 数据形式 | 参数配置包 |
| 对应状态 | S1、S2、S4、S5，按需配置 |

建议字段：

| 字段 | 含义 | 建议类型 |
|---|---|---|
| `slot_id` | slot 序号 | `uint32` |
| `work_mode` | 工作模式：搜索、粗对准、辅助跟踪、回退恢复 | `uint8` |
| `report_period_slot` | 上报周期，单位 slot | `uint16` |
| `detect_window_slot` | 稳定检测窗口 | `uint16` |
| `valid_threshold` | 目标有效判决阈值 | `float32` 或定点数 |
| `angle_filter_alpha` | 角度滤波参数，可选 | `float32` 或定点数 |
| `reserved` | 预留字段 | bytes |

### 3.4 LF-IF-04 低频通信/感知数据接口

| 项目 | 内容 |
|---|---|
| 方向 | 低频通感基带 <-> 控制板/上层链路 |
| 发送方 | 低频通感基带或控制板 |
| 接收方 | 控制板或上层链路 |
| 物理口 | 待硬件确认；现有图中标注“通信数据”“通信/感知数据” |
| 数据形式 | 通信数据帧、感知数据帧或二者复用帧 |
| 对应状态 | S4 跟踪时可能使用；S1/S2/S5以感知数据为主 |

建议数据分类：

| 数据类型 | 方向 | 内容 |
|---|---|---|
| 感知数据 | 低频通感基带 -> 控制板 | 目标角度、距离、速度、置信度、目标有效标志 |
| 通信数据 | 低频通感基带 -> 控制板/上层 | 通信帧、链路质量、误码/丢包统计 |
| 控制数据 | 控制板 -> 低频通感基带 | 模式切换、参数配置、启停控制 |

### 3.5 LF-IF-05 低频设备在线/健康状态接口

| 项目 | 内容 |
|---|---|
| 方向 | 低频通感基带/射频 -> 控制板 |
| 发送方 | 毫米波通感系统 |
| 接收方 | 转化模块 DSP / 控制板 |
| 物理口 | 待硬件确认；可复用低频数字通信链路 |
| 数据形式 | 心跳包/状态字 |
| 对应状态 | S0 自检、运行期故障监控 |

建议字段：

| 字段 | 含义 | 建议类型 |
|---|---|---|
| `slot_id` | slot 序号 | `uint32` |
| `baseband_online` | 低频基带在线状态 | `uint8/bool` |
| `rf_online` | 低频射频在线状态 | `uint8/bool` |
| `clock_sync_ok` | 时钟/时间同步状态 | `uint8/bool` |
| `temperature_status` | 温度状态，可选 | `uint8` |
| `fault_code` | 故障码 | `uint16/uint32` |
| `heartbeat_counter` | 心跳计数 | `uint32` |

## 4. Slot 内建议时序

每个 slot 内建议按如下顺序处理控制板与低频通感设备之间的数据：

| 顺序 | 阶段 | 数据包/动作 | 方向 |
|---|---|---|---|
| 1 | T0 同步/自检 | 低频设备在线/健康状态检查 | 低频通感设备 -> 控制板 |
| 2 | T1 感知输入 | 低频目标感知数据包 | 低频通感基带 -> 控制板 |
| 3 | T2 控制下发 | 低频通感启停控制、通信参数配置 | 控制板 -> 低频通感基带 |
| 4 | T3 反馈确认 | 参数生效状态、模式确认，可选 | 低频通感基带 -> 控制板 |
| 5 | T5 状态上报 | 控制板将当前状态上报给上层 | 控制板 -> 上层 |

## 5. 需要硬件进一步确认的内容

以下内容当前设计资料中尚未明确，建议在硬件接口文档中补齐：

| 待确认项 | 说明 |
|---|---|
| 具体物理口类型 | 控制板与低频通感基带之间究竟使用以太网、串口、RS422、RS485、CAN、SPI、LVDS或其他接口 |
| 连接器型号 | 板端连接器、线缆、针脚定义 |
| 电气标准 | 电平、差分/单端、隔离要求、终端匹配 |
| 传输速率 | 波特率、网口速率、SPI时钟或其他链路速率 |
| 帧格式 | 帧头、长度、类型、序号、校验、大小端 |
| 时间同步 | `slot_id` 与系统时钟/1PPS的对应关系 |
| 错误处理 | 超时、丢包、CRC错误、设备离线时的处理策略 |

## 6. 建议统一帧格式

如果后续需要把上述接口落到代码和联调协议，建议采用统一帧头：

| 字段 | 含义 | 建议类型 |
|---|---|---|
| `magic` | 帧头标识 | `uint16` |
| `version` | 协议版本 | `uint8` |
| `msg_type` | 消息类型，对应 LF-IF-xx 或具体包 ID | `uint8` |
| `seq` | 包序号 | `uint16` |
| `slot_id` | slot 序号 | `uint32` |
| `timestamp` | 时间戳 | `uint64` |
| `payload_len` | 负载长度 | `uint16` |
| `payload` | 具体业务字段 | bytes |
| `crc` | 校验 | `uint16/uint32` |

## 7. 状态机相关性

| 状态 | 低频通感设备参与方式 |
|---|---|
| S0 自检 | 控制板检查低频基带/射频是否在线 |
| S1 搜索 | 低频通感设备持续上报目标感知数据 |
| S2 粗对准 | 控制板根据低频角度信息控制云台粗对准 |
| S3 捕获 | 低频通感不是主链路，可保留辅助/健康状态 |
| S4 跟踪 | 低频感知作为太赫兹跟踪的辅助输入 |
| S5 回退 | 太赫兹失锁后，低频通感设备承担恢复目标的主输入 |
