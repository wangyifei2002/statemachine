# STM32H743 阿波罗开发板 - 工业双轴云台（舵机）控制模块

本模块（`duoji/`）实现了利用正点原子阿波罗 V2 开发板（STM32H743）对精密双轴云台主机的驱动控制。

## 1. 通信协议
* **协议类型**：Pelco-D 协议 (安防工业标准)
* **物理层接口**：RS485 总线 (板载 120Ω 终端电阻)
* **串口参数**：波特率 9600 / 8 位数据位 / 1 位停止位 / 无校验
* **设备默认地址**：0x01

### 数据帧结构
每个指令包含 7 个字节：`[0xFF] [ADDR] [CMND1] [CMND2] [DATA1] [DATA2] [CKSM]`

---

## 2. 硬件接线与底板配置

### 硬件引脚对齐
* **云台黑线 (485A)** -> 开发板 RS485 接口 **A 端**
* **云台橙线 (485B)** -> 开发板 RS485 接口 **B 端**
* **独立供电**：云台使用外部 **DC 24V 工业电源**，开发板与外部电源必须 **共地 (GND)**。

### 底板跳线配置 (重要)
由于底板引脚复用，必须使用跳线帽短接 **P7 排针** 以启用 RS485 模式。此时：
* `PA2` 映射为 `UART2_TX` (通过 TP8485 发射)
* `PA3` 映射为 `UART2_RX` (通过 TP8485 接收)
* 硬件收发方向切换控制引脚：I/O 扩展芯片 **PCF8574 的 P6 引脚** (`RS485_RE`)

---

## 3. 软件架构说明
* `Set_RS485_TxMode()` / `Set_RS485_RxMode()`：控制 PCF8574 切换 RS485 芯片的收发流向。
* `PelcoD_SendCmd(...)`：动态计算 Checksum 并通过 UART2 发送 7 字节控制指令。
